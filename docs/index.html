Wireless Battery Tray

Battery levels of your wireless keyboards, mice, headsets and controllers, right on the Windows taskbar of the monitor you choose.

Download for Windows View on GitHub

What it does

  • Always in viewOne icon and percentage per device, inside the taskbar next to the clock.
  • Any monitorPick the display, left or right side, and an offset.
  • Charging and low batteryA bolt while charging, red below your chosen level.
  • Out of the wayHides with the taskbar in full-screen apps and follows light/dark mode.
  • Your layoutShow, hide, reorder and relabel devices with a live preview.
  • Read-onlyOnly ever queries devices. Optional, click-to-install updates.

Install

  1. Download wireless-battery-tray.exe (or the zip) from the latest release.
  2. Put it anywhere, for example %LOCALAPPDATA%\Programs\Wireless Battery Tray\, and run it.
  3. Windows SmartScreen may warn that the app is unrecognised because it isn't code-signed yet: choose More info, then Run anyway.
  4. To start it at login, tick Start with Windows in the tray menu or in Settings.

Requires Windows 10 or 11, x64. The zip also contains wbt.exe, a command-line tool that prints every battery once (wbt --json for JSON). Settings are saved to %APPDATA%\wireless-battery-tray\config.toml.

Known limitations

  • Keychron keyboards on a Keychron Link receiver report no battery over 2.4 GHz and show as connected only. In Bluetooth mode they report battery normally.
  • The Logitech MX Master 3 reports no level while charging, so only the charging bolt shows until it reports a level again.
  • ZMK split keyboards such as the Glove80 show only the central half unless the firmware is built with CONFIG_ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_PROXY=y and CONFIG_ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_FETCHING=y.
  • SteelSeries Arctis headsets on older firmware report battery in 25% steps; the DualShock 4 reports in 10% steps.

Questions

How do I see my Bluetooth headphones' or mouse's battery on the Windows taskbar?
Run Wireless Battery Tray. It adds a small strip inside the Windows 10/11 taskbar with an icon and percentage for every connected wireless keyboard, mouse, headset, earbuds and controller.
Does it show Logitech battery without Logi Options+?
Yes. Logitech devices on Unifying, Bolt and Lightspeed receivers are read over HID++ 2.0, with or without Logi Options+, including the charging state.
Can it show both halves of a split keyboard like the Glove80?
Yes, every BLE battery value is shown. ZMK split keyboards show both halves when the firmware is built with CONFIG_ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_PROXY=y.
